# Развитие на будущее

Идеи, сознательно не вошедшие в первую версию. Это не обязательства и не порядок работ.

## Диагностика

- Ping шлюза, DNS и прокси из окна инструмента; проверка доступности прокси после применения.

## Другие сетевые настройки

- Маршруты.
- Правка `hosts`.
- Смена MAC-адреса адаптера.
- Имя компьютера и домен.
- IPv6.
- Несколько адресов на адаптере, метрики, WINS, DNS-суффиксы.
- Управление Wi-Fi-сетями (подключение, пароли).

## Прокси

- Отдельные прокси по протоколам, SOCKS.
- Сценарий автонастройки (PAC) и автоопределение как часть профиля.

## Профили и применение

- Одновременное применение к нескольким адаптерам.
- Группы и поиск профилей (когда профилей станет больше ~20).
- Запоминание последнего введённого уточняемого адреса по компьютерам.
- Откат, переживающий перезапуск инструмента (история на флешке).
- Автооткат «не подтвердил за N секунд» для работы через удалённый доступ.

## Запуск и оболочка

- Командная строка (применить профиль без окна).
- Значок в трее.
- Автозапуск.
- Подпись exe сертификатом.
