# C# + WinForms на .NET Framework 4.x

Инструмент должен запускаться с флешки одним exe, ничего не устанавливать и не записывать на управляемый компьютер, работать от Windows 7 до Windows 11 и не раздражать антивирусы (Defender на 10/11, Dr.Web на 7/8). Пишем на C# + WinForms под .NET Framework 4.x: он встроен в Windows 8/10/11, даёт exe в сотни килобайт без файлов-спутников и позволяет менять настройки через WMI и WinAPI внутри процесса.

## Considered Options

- **C++ / чистый Win32** — ноль зависимостей даже на голой Windows 7, но заметно дороже в разработке и развитии интерфейса.
- **Rust** — Windows 7 не поддерживается с версии 1.78; неподписанные бинарники чаще ловят эвристику антивирусов.
- **.NET 8+ self-contained** — 60+ МБ, нет Windows 7, single-file распаковывает библиотеки во временную папку управляемого компьютера.
- **Python + PyInstaller/Nuitka** — режим «один файл» распаковывается в `%TEMP%` при каждом запуске (запись на управляемый компьютер), загрузчик PyInstaller — частый источник ложных срабатываний антивирусов, Windows 7 поддерживает только снятый с поддержки Python 3.8.

## Consequences

- На Windows 7, где .NET Framework 4.x не установлен, инструмент не запустится — это осознанно вне гарантии.
- Современные возможности .NET и свежие библиотеки недоступны; зависимости от NuGet-пакетов, которые нужно класть рядом с exe, исключены.
