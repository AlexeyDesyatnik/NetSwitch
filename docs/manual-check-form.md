# Форма итогов ручной проверки

Заполняется при проходе по [чек-листу](manual-check.md). Заполненную форму в репозиторий не выкладывайте: в ней адреса управляемого компьютера.

Одна форма на один управляемый компьютер. В графе результата: «да» — совпало с ожидаемым, «нет» — расхождение, «—» — не проверялось.
