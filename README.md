# NetSwitch

Быстрое переключение IPv4-настроек сетевого адаптера в Windows 10/11:
«Автоматически (DHCP)» ⇄ сохранённые профили с ручными IP, маской, шлюзом и DNS.
Без Панели управления, без установки — только PowerShell 5.1, который есть в системе.

## Запуск

1. Если файлы скачаны из интернета: «Свойства» → «Разблокировать».
2. Двойной щелчок по `NetSwitch.bat`. Права администратора скрипт запросит сам (UAC).

## Окно

- **Адаптер** — список адаптеров (подключённые сверху) и их текущие настройки.
- **Профили**:
  - `Автоматически (DHCP)` — получать адрес и DNS автоматически;
  - `Вручную (без профиля)` — разовая настройка из полей;
  - дальше — сохранённые профили.
- **Двойной щелчок** по профилю или **Enter** — применить.
- **Взять текущие** — подставить в поля то, что сейчас стоит на адаптере.
- **Сохранить как…** — записать поля в профиль (с тем же именем — перезаписать).
- **Ярлык на рабочий стол** — ярлык, который применяет выбранный профиль без окна.

Маску можно вводить как `255.255.255.0` или `24` / `/24`. Шлюз и DNS необязательны.

## Командная строка

```bat
NetSwitch.bat -Profile "Кабинет"
NetSwitch.bat -Profile "Кабинет" -Adapter "Ethernet"
NetSwitch.bat -Profile DHCP -Adapter "Беспроводная сеть"
```

`DHCP`, `auto` и `авто` — зарезервированные имена для автонастройки.
Без `-Adapter` берётся последний адаптер, к которому применяли профиль из окна.

## Профили

Хранятся в `profiles.json` рядом со скриптом; файл создаётся при первом запуске
с примером. Формат:

```json
{
  "DefaultAdapter": "Ethernet",
  "Profiles": [
    {
      "Name": "Кабинет",
      "IP": "192.168.1.50",
      "Mask": "255.255.255.0",
      "Gateway": "192.168.1.1",
      "DNS": ["192.168.1.1", "8.8.8.8"]
    }
  ]
}
```

`profiles.json` в git не попадает (см. `.gitignore`) — это личные настройки.
Бэкап — просто скопировать файл.

## Как это устроено

| Что | Чем |
|---|---|
| IP, маска, шлюз, включение DHCP | `netsh interface ipv4 set address` (по индексу интерфейса — без проблем с кириллицей и пробелами в именах) |
| DNS | `Set-DnsClientServerAddress` |
| Старый ручной шлюз | удаляется из PersistentStore (`Remove-NetRoute`) перед каждым переключением |
| Текущее состояние | `Get-NetIPInterface`, `Get-NetIPAddress`, `Get-NetRoute`, `Get-DnsClientServerAddress` |
| Окно | WinForms |
| Ярлыки | `WScript.Shell` |

Структура `NetSwitch.ps1`: параметры → самоповышение прав → конфиг →
проверка адресов → работа с адаптером → режим без окна → окно.

## Ограничения

- Только IPv4.
- Ярлыки содержат полный путь к скрипту: если перенести папку, их нужно пересоздать.
- Каждый запуск показывает окно UAC.

## Разработка

- **`NetSwitch.ps1` должен оставаться в UTF-8 с BOM.** Windows PowerShell 5.1 читает
  файлы без BOM как ANSI (cp1251), и вся кириллица ломается. VS Code: в строке
  состояния кодировка → «Save with Encoding» → «UTF-8 with BOM». `.editorconfig`
  в репозитории это задаёт автоматически для редакторов, которые его понимают.
- Концы строк — CRLF (задано в `.gitattributes`).
- `NetSwitch.bat` — только ASCII: cmd читает его в OEM-кодировке.
- Проверить синтаксис без запуска:

  ```powershell
  $e = $null
  [void][System.Management.Automation.Language.Parser]::ParseFile("$PWD\NetSwitch.ps1", [ref]$null, [ref]$e)
  $e
  ```
