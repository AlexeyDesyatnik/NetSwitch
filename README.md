# NetSwitch

Портабельный инструмент для быстрой смены сетевых настроек Windows: адреса IPv4, DNS и прокси. Носится на флешке одним exe, ничего не устанавливает и не оставляет на компьютере ничего, кроме самих сетевых настроек.

Сделан для тех, кому приходится переключать один и тот же компьютер между сетями с разными настройками — например, между офисной сетью с прокси и стендом со статическими адресами.

## Что умеет

- **Профили** — именованные наборы настроек IPv4 и прокси. Применяются к адаптеру, выбранному в окне, двойным щелчком; перед применением показывается, что было и что станет. Адрес в профиле можно задать не полностью (только подсеть) и дополнить при применении.
- **Ручная правка** настроек адаптера и прокси без профиля.
- **IPv4**: автоматически (DHCP) или вручную — адрес, маска, шлюз, до двух DNS-серверов. Работает и при отключённом кабеле, и на выключенном адаптере.
- **Прокси**: одна настройка сразу для системного прокси пользователя и для WinHTTP-прокси, которым пользуются службы Windows и Центр обновления.
- **Включение и выключение адаптеров**.
- **Откат** к настройкам, которые были до последнего применения.
- **Отчёт** о компьютере, адаптерах и результатах применения — по команде, в папку рядом с exe, для разбора проблем.

Профили хранятся в `NetSwitch.json` рядом с exe.

## Требования

- Windows 7 – Windows 11 с .NET Framework 4.0 или новее (в Windows 8, 10 и 11 он уже есть; на Windows 7 его может не быть).
- Права администратора: инструмент запрашивает их при запуске.

## Скачать

Готовый `NetSwitch.exe` — на странице [Releases](https://github.com/AlexeyDesyatnik/NetSwitch/releases). Exe не подписан, поэтому Windows SmartScreen при первом запуске предупредит о неизвестном издателе.

Проект в ранней стадии: запись настроек проверена ещё не на всех версиях Windows. Перед тем как полагаться на инструмент, проверьте его на адаптере, через который вы сейчас не работаете.
